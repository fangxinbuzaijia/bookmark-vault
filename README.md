# 收藏夹保险箱 / Bookmark Vault

给 Chrome 和 Edge 收藏夹加一道真正的锁。

收藏夹保险箱可将敏感收藏移出浏览器原生收藏夹，用主密码在本地加密保存；解锁后可在隐身窗口打开，并把加密快照备份到本地文件、Google Drive、OneDrive、Dropbox、WebDAV 或 S3。

- [免费安装](https://chromewebstore.google.com/detail/agepfpohppnlmjipbigfikpmbfkkhdga)
- [产品网站](https://fangxinbuzaijia.github.io/bookmark-vault/)
- [隐私政策](https://fangxinbuzaijia.github.io/bookmark-vault-privacy/)

## 安全摘要

- AES-256-GCM 加密
- PBKDF2，600,000 次迭代
- 主密码不持久保存、不传输
- 没有开发者后台、广告、分析或行为追踪
- 忘记主密码后无法恢复
